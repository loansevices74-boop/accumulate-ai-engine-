# ⚡ Accumulate AI Engine
Global Multi-Sport 20-Leg Accumulator Machine (>70% Probability).
Covers Football & Basketball domestic leagues worldwide, UEFA/continental tournaments, and international events.

## Deploy
1. Push to GitHub (Public repo)
2. Deploy on Streamlit Cloud (main file: app.py)
3. Add Secrets: ODDS_API_KEY, QWEN_API_KEY, QWEN_BASE_URL
